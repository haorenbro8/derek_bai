📱 安装到手机

将系统安装到手机桌面，可像原生 APP 一样全屏启动，无需每次打开浏览器。
🤖 安卓手机（Chrome 浏览器）
1
用 Chrome 打开本系统网址

需要将 HTML 文件上传到 HTTPS 网址才能安装。可使用 GitHub Pages（免费）托管。

2
点击右上角菜单（⋮）

在 Chrome 地址栏右侧点击三点菜单图标。

3
选择「添加到主屏幕」或「安装应用」

点击后按提示确认，桌面会出现"到货核对"图标，点击即可全屏启动。

iOS 苹果手机
1
用 Safari 浏览器打开本系统网址

iOS 只支持 Safari 添加到桌面，请勿使用其他浏览器。

2
点击底部分享按钮（□↑）

在 Safari 底部工具栏找到分享图标并点击。

3
选择「添加到主屏幕」

向下滚动找到该选项，点击"添加"即完成安装。

💡 免费托管方法（推荐 GitHub Pages） ① 注册 GitHub 账号 → ② 新建仓库并上传 HTML 文件 → ③ 仓库设置中开启 Pages → ④ 获得 https://你的名字.github.io/仓库名 网址即可访问安装
